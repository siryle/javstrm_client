# iOS 实机验收

这些项目需在完整 Xcode 和可访问的 JavStrm 服务环境中执行。目前尚未执行。

## 构建与连接

- 使用 JavStrm Scheme 在 iOS 17 及当前 iOS 模拟器构建；真机配置自己的签名 Team。
- iPhone 竖屏、小屏、横屏和 iPad 分屏下检查网格、列表、键盘和大字号。
- 填写 Gitea 仓库地址应显示「未返回 JavStrm 接口」，不能进入业务页面。
- 用正确的 HTTP 局域网服务连接；拒绝本地网络权限后确认错误可理解，允许后可重试。
- 分别测试启用门禁和关闭门禁的后端；错误密码、正确密码、退出及重新启动。
- 测试 HTTPS 地址、非默认端口及配置正确的反向代理子路径。
- 服务不可达、超时和恢复时检查加载状态、错误提示及重试。

## 原生功能

- 媒体库逐页加载无重复；切换目录和新入库筛选后不残留旧结果。
- 本地媒体库搜索只筛选已加载结果，继续加载按钮仍然可用。
- 发现页默认显示「最新作品」，依次切换「热门作品」「高分作品」「即将发行」，确认结果与服务端对应标签页一致，且无分类筛选入口。
- 发现页各标签的下一页、下拉刷新、空结果、失败重试与快速切换；切换后不残留旧标签结果。搜索提交、清空后恢复当前标签及搜索分页正常。
- 对已发售、未发售及没有磁力的作品点击卡片订阅；创建成功后立即显示「已订阅」并触发检查，暂无匹配资源时仍显示「已订阅」，有资源时变为「已加入离线」，已入库时变为「已入库」。
- 立即检查失败时保留订阅和错误提示；离开再返回、下拉刷新及服务端定时检查后，stale / error 订阅仍显示「已订阅」，避免重复创建。
- 作品详情、演员信息、标签、订阅状态和磁力列表。
- 创建作品订阅、取消订阅、开关自动下载；订阅超过 100 条时详情仍能找到正确状态。
- 演员订阅、暂停 / 恢复，以及演员新作列表分页。
- 磁力下载需确认；提交成功后在任务页找到对应离线任务。
- 对服务端支持的独立任务验证暂停 / 恢复 / 终止，对离线下载验证终止。
- 原生工具页修改并保存整理、刮削和 STRM 配置后启动任务；验证按组 / 全部生成、定时计划、空目录清理、Emby 演员补全及任务输出。
- 115 网盘未连接、登录过期、已连接和容量显示。
- 点击「登录网盘与配置目录」进入原生页面；分别选择支付宝、微信及 115 客户端扫码方式，确认二维码、已扫码与授权状态正常，授权后返回网盘设置并更新账号信息。
- 验证二维码过期、取消、获取失败与重新获取；快速切换扫码方式时旧请求不能覆盖新二维码，网络短暂中断后继续查询，连续失败后可手动重试。
- 扫码页进入后台停止轮询，返回前台继续查询原二维码；授权完成后切后台再返回仍能更新账号并退出扫码页，离开页面后不再轮询。
- 在原生目录选择页逐层进入 / 返回、跳转根目录及分页；包含普通文件但没有子目录时仍能选择当前目录，下载 / 整理目录分别保存和清除，失败时在当前页面显示错误并允许重试。
- 原生网盘退出需确认，完成后账号与目录状态更新，App 的服务器登录仍保持。
- 本地文件和网盘目录逐层浏览、空目录、分页及文件信息。
- 原生文件管理分别测试本地与 115 的复制、移动、重命名、批量删除；选择源目录和目标目录、根目录与上级目录、最多 100 个选择、无效名称、权限不足及部分失败提示；操作完成后刷新列表。
- 115 账号在浏览或操作过程中变更时，不能误操作另一账号的文件。
- 原生任务历史按类型浏览、搜索、翻页并查看完整处理结果；快速 STRM 历史和多页生成结果正常。

## 实时与会话

- SSE 在空闲状态持续收到心跳；新任务、进度和完成状态自动更新。
- 关闭服务或断开网络后显示重连状态；恢复后获取新快照并继续刷新离线任务。
- 在任务完成、作品入库和订阅更新后，对应列表刷新。
- 让 App Cookie 过期，任何 `AUTH_REQUIRED` 请求都回到登录界面。
- 单独让 115 Cookie 过期，App 登录仍保持，网盘相关错误正常显示。
- 请求进行中更换服务器，旧服务器响应不能覆盖新服务器数据。
- 进入后台停止同步，返回前台恢复；反复切换不会重复创建同步任务。

## 原生管理与隐私

- 设置页的工具、完整设置和文件管理入口，以及任务页的配置工具 / 任务历史入口，均进入原生页面，无服务端网页弹窗。
- 修改代理、刮削源、订阅偏好、Emby 配置和各项生成规则后保存，返回并重新进入时读取一致；测试代理及 Emby 连接，失败可重试。
- 编辑 Emby 设置、嵌套偏好和配置组时，未修改的 API Key、路径映射、null 字段和其他服务端字段保持原值；新增 / 删除配置组后正确保存。
- Emby 媒体库选择、标题 / 副标题、原生封面预览及上传正常；修改配置后清除旧预览，生成过程中隐藏封面或离开页面停止后续生成，切换 Emby 配置后旧预览不可上传。
- 原生配置导出后可重新导入；无效格式 / 版本 / 超大文件拒绝，导入与缓存清理需确认，操作后结果与重启提示正确。
- 默认海报占位；隐藏封面时不发出图片请求；开启后正确使用服务端图片代理。
- 媒体库详情展示完整横向图，优先使用 fanart；列表仍优先展示 poster。
- 媒体库卡片点击番号或标题进入详情，点击封面进入裁切，卡片无独立裁切按钮；详情保留裁切工具栏按钮。默认选中原图右侧 2:3 区域；拖动选框、调整右下角控制点、重置及旋转屏幕后，选框比例和图片边界正确。
- 保存裁切后后台与客户端列表展示同一封面；已加载多页时仍保留这些页面，原始横向图保持不变。保存失败时显示错误并保留选框以便重试。
- 隐藏封面或只有 poster 而没有 fanart / cover 时不可裁切；保存过程中不能重复提交或关闭裁切页。
- 打开原生详情、磁力弹窗、文件操作 / 目录选择弹窗及封面预览，切后台检查内容被遮罩。
- 系统权限提示、通知中心、应用切换器和回到前台后，遮罩显示 / 隐藏正确。
- Keychain 中仅保存会话 Token，UserDefaults 只保存服务地址、用户名与显示偏好。
