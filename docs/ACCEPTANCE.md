# iOS 实机验收

这些项目需在完整 Xcode 和可访问的 JavStrm 服务环境中执行。目前尚未执行。

## 构建与连接

- 使用 JavStrm Scheme 在 iOS 17 及当前 iOS 模拟器构建；真机配置自己的签名 Team。
- iPhone 竖屏、小屏、横屏和 iPad 分屏下检查网格、列表、键盘和大字号。
- 填写 Gitea 仓库地址应显示「未返回 JavStrm 接口」，不能进入业务页面。
- 用正确的 HTTP 局域网服务连接；拒绝本地网络权限后确认错误可理解，允许后可重试。
- 分别测试启用门禁和关闭门禁的后端；错误密码、正确密码、退出及重新启动。
- 测试 HTTPS 地址、非默认端口及配置正确的反向代理子路径。
- 服务不可达、超时和恢复时检查加载状态、错误提示及重试。

## 原生功能

- 媒体库逐页加载无重复；切换目录和新入库筛选后不残留旧结果。
- 本地媒体库搜索只筛选已加载结果，继续加载按钮仍然可用。
- 发现分类、排序、搜索提交、搜索清空、下一页及空结果。
- 作品详情、演员信息、标签、订阅状态和磁力列表。
- 创建作品订阅、取消订阅、开关自动下载；订阅超过 100 条时详情仍能找到正确状态。
- 演员订阅、暂停 / 恢复，以及演员新作列表分页。
- 磁力下载需确认；提交成功后在任务页找到对应离线任务。
- 对服务端支持的独立任务验证暂停 / 恢复 / 终止，对离线下载验证终止。
- 使用预先配置的整理和 STRM 生成设置启动任务，并核对实际输出。
- 115 网盘未连接、登录过期、已连接和容量显示。
- 本地文件和网盘目录逐层浏览、空目录、分页及文件信息。

## 实时与会话

- SSE 在空闲状态持续收到心跳；新任务、进度和完成状态自动更新。
- 关闭服务或断开网络后显示重连状态；恢复后获取新快照并继续刷新离线任务。
- 在任务完成、作品入库和订阅更新后，对应列表刷新。
- 让 App Cookie 过期，任何 `AUTH_REQUIRED` 请求都回到登录界面。
- 单独让 115 Cookie 过期，App 登录仍保持，网盘相关错误正常显示。
- 请求进行中更换服务器，旧服务器响应不能覆盖新服务器数据。
- 进入后台停止同步，返回前台恢复；反复切换不会重复创建同步任务。

## Web 与隐私

- 从 App 打开设置 / 工具无需再次登录；Web 页面内退出登录后关闭页面，App 同步退出。
- 扫码登录 115、选择目录、修改 Emby 配置和生成规则后，服务端保存结果。
- Web 弹出链接和 JavaScript 确认框正常响应；外部主框架链接在系统浏览器打开。
- 默认海报占位；隐藏封面时不发出图片请求；开启后正确使用服务端图片代理。
- 打开原生详情、磁力弹窗、文件信息弹窗及 Web 管理页面，切后台检查内容被遮罩。
- 系统权限提示、通知中心、应用切换器和回到前台后，遮罩显示 / 隐藏正确。
- Keychain 中仅保存会话 Token，UserDefaults 只保存服务地址、用户名与显示偏好。
